# Dataset Documentation

This document describes the datasets used and supported by the Fake News Detection System: the bundled **Synthetic Demonstration Dataset** and the real-world **ISOT Fake News Dataset**.

---

## 1. Bundled Synthetic Demonstration Dataset

### Overview
- **File location:** `data/raw/demo_news.csv` (auto-generated by `src/make_demo_data.py` if not present)
- **Size:** 1,000 articles (500 Real, 500 Fake; ~999 after deduplication)
- **Format:** CSV with columns `text` and `label` (0 = REAL, 1 = FAKE)
- **Purpose:** Allows students, examiners, and evaluators to run the complete pipeline out-of-the-box (data loading, preprocessing, model training, evaluation, explainability, web dashboard) without downloading multi-gigabyte external archives.

### Known Limitations & Why Scores Reach 100%
The classical models (Logistic Regression, Naive Bayes, Linear SVM) and fine-tuned DistilBERT achieve near-100% accuracy on this dataset. **This is an intentional design property of the demonstration data generator, not an indicator of real-world fake news detection capability:**

1. **Deliberate Stylistic Contrast:** The synthetic generator creates Real articles using formal journalistic templates (*e.g., "According to officials...", "Researchers reported...", passive attribution*) and Fake articles using sensationalist clickbait templates (*e.g., "SHOCKING BOMBSHELL...", "SECRET plot they DON'T want you to know...", all-caps phrases, exclamation marks*).
2. **Vocabulary Separation:** As a consequence, TF-IDF unigram and bigram features find perfectly separable vocabulary distributions (*e.g., "shocking", "whistleblower", "miracle" vs. "officials", "progress", "committee"*).
3. **Absence of Real-World Ambiguity:** Real-world disinformation frequently mimics reputable wire services (Reuters, AP) in tone, grammar, and formal vocabulary.
4. **Academic Caveat:** Presenting 100% accuracy on this demo dataset as evidence of solving fake news detection would be scientifically misleading. The demo proves that the software engineering and machine learning pipelines function properly; evaluating on real-world datasets like ISOT is required for meaningful academic benchmarks.

## 2. Real-World Benchmark: ISOT Fake News Dataset

### Overview
- **Provider:** University of Victoria Information Security and Object Technology (ISOT) Research Lab.
- **Source URL:** https://onlineacademiccommunity.uvic.ca/isot/2022/11/27/fake-news-detection-datasets/
- **Kaggle Mirror:** "Fake and Real News Dataset" by Clément Bisaillon:
  https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset
- **Size:** ~44,900 articles total (~21,400 real, ~23,500 fake).
- **Format:** Two CSV files:
  - `data/raw/True.csv` (real news from Reuters wire stories)
  - `data/raw/Fake.csv` (fabricated news stories from unverified web sources)
- **Schema:** Each CSV contains columns: `title`, `text`, `subject`, `date`.

### How the Pipeline Loads ISOT
`src/data_loader.py` handles the ISOT dataset automatically:
1. **Detection:** Checks whether both `data/raw/True.csv` and `data/raw/Fake.csv` exist.
2. **Label Assignment:**
   - Articles from `True.csv` are explicitly assigned `label = 0` (REAL).
   - Articles from `Fake.csv` are explicitly assigned `label = 1` (FAKE).
3. **Text Merging:** Combines `title` and `text` into a unified `text` body (`"{title}. {body}"`).
4. **Validation & Cleaning:**
   - Strips whitespace.
   - Drops rows with missing or empty text.
   - Drops near-empty articles (length $\le 20$ characters).
   - Strips common source datelines (e.g. `WASHINGTON (Reuters) -`) during preprocessing to reduce dataset artefacts.
   - Deduplicates text to prevent data leakage between train and test splits.
5. **Stratified Splitting:** Uses a fixed random seed (`SEED=42`) to produce 70% train, 15% validation, and 15% test splits.
6. **Metadata Recording:** Saves provenance details in `data/processed/dataset_info.json`.

### How to Use ISOT in this Project
1. Download `True.csv` and `Fake.csv` from Kaggle or the ISOT lab.
2. Place both files in the project's `data/raw/` directory:
   ```
   data/raw/True.csv
   data/raw/Fake.csv
   ```
3. Run training with `--force-reprocess`:
   ```bash
   python -m src.train --force-reprocess
   ```
4. Run evaluation:
   ```bash
   python -m src.evaluate
   ```
5. View results in the web dashboard:
   ```bash
   streamlit run src/app.py
   ```

## 3. Dataset Summary Comparison

| Attribute | Synthetic Demo Dataset | ISOT Fake News Dataset |
| :--- | :--- | :--- |
| **Availability** | Bundled / Auto-generated | User-supplied download |
| **Total Articles** | ~1,000 | ~44,900 |
| **Real / Fake Balance** | 50% / 50% (balanced) | ~48% / ~52% (balanced) |
| **Source of Real** | Algorithmic templates | Reuters wire reporting |
| **Source of Fake** | Algorithmic clickbait templates | Fabricated news stories from unflagged sources |
| **Expected Accuracy** | ~100% (synthetically separable) | ~90% - 98% depending on dateline stripping |
| **Intended Role** | Software verification & demonstration | Academic benchmarking |
